# GPTgrill-Codexwork v0.2.0

Initial usable release of the repo-driven GPTgrill-Codexwork orchestration workflow.

## Included release assets

A tagged `v0.2.0` release should publish:

- `grill-me-web-skill-v0.2.0.zip`
- `gptgrill-codexwork-web-skill-v0.2.0.zip`
- `gptgrill-codexwork-local-v0.2.0.tgz`
- `gptgrill-codexwork-local-v0.2.0.zip`
- `SHA256SUMS.txt`
- GitHub-generated source archives

## Highlights

- ChatGPT Web `Grill Me` Skill for requirements clarification.
- ChatGPT Web `GPTgrill-Codexwork` Skill for spec/phase/task dispatch.
- Local GPTgrill-Codexwork Runner with `task`, `phase`, and `goal` autonomy modes.
- Revision-based human gates for task/phase continuation.
- Dedicated goal branches and local runtime state.
- Integration with an existing `codex-with-chatgpt` installation.
- Task-level, phase-level, and final review loops.
- Phase/final reports.
- macOS launchd watcher.
- Automated tagged release packaging.

## Codex App note

Codex App is compatible with GPTgrill-Codexwork and can remain the normal interactive UI. GPTgrill-Codexwork v0.2.0 still launches autonomous work through the local `codex` CLI executable, so `which codex` and `codex --version` must succeed on the machine.

GPTgrill-Codexwork does not currently drive the Codex App GUI directly.

## Create this release

Make sure `main` is up to date and checks pass, then:

```bash
git checkout main
git pull --ff-only
npm ci
npm run check
git tag -a v0.2.0 -m "GPTgrill-Codexwork v0.2.0"
git push origin v0.2.0
```

The Release workflow will package and publish the assets automatically.
