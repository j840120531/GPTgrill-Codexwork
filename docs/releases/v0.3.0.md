# GPTgrill-Codexwork v0.3.0

v0.3.0 completes the product-wide rename to **GPTgrill-Codexwork**.

Breaking identifier changes:

- npm package: `gptgrill-codexwork`
- CLI: `gptgrill-codexwork`
- repo control directory: `.gptgrill-codexwork/`
- runtime state directory: `~/.gptgrill-codexwork/`
- default work branch prefix: `gptgrill-codexwork/`
- environment prefix: `GPTGRILL_CODEXWORK_`
- launchd/log identifiers now use `gptgrill-codexwork`
- orchestration web skill slug: `gptgrill-codexwork`

Existing pre-v0.3 installations should remove the old global link/package before linking or installing v0.3.0.
